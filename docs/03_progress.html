Read the two numbers together

4% of the effort has retired 92% of the risk. That is exactly what P0 is designed to do, and it is the right shape for this point in a project. Almost nothing has been built yet — but nearly everything that could have wrecked the build has been found and answered before a single line of pipeline code was written. Two of them (the incompatible model layers, the silently-resetting privacy accountant) would have surfaced weeks in, after work had been stacked on top of them.

The dataset blocker is cleared. Synthea was tested, failed, and has been replaced by a real ICU dataset that was put through the same tests and passed. Both tracks can now proceed.

No time has been wasted so far: nothing built has had to be thrown away, because almost nothing has been built.

How the labelling question resolved

The new dataset ships a sepsis label, which would have quietly turned the project into a sepsis classifier. Instead, NEWS2 scores are computed from the real vitals — the labelling scheme originally intended, which Synthea could not support. That gives 12.6% of hours as deteriorating, matching the 10–15% the original documents assumed, so the planned loss weighting holds after all.

It also produced an unexpected gain: the dataset's clinical sepsis adjudication becomes an independent check on the derived labels, which flagged 60–75% of septic patients. Validating a rule-based label against real clinical judgement is a stronger argument than the originally planned comparison against a second rule.

One genuine limitation remains: the two hospital sites differ mainly in what they measure rather than in their patients, so the federation is heterogeneous but more mildly than the design assumed.
